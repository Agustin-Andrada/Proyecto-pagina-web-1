# Proyecto-pagina-web-1

📄 Descripción del proyecto
Este proyecto consiste en el desarrollo de un sitio web para un complejo deportivo barrial enfocado principalmente en el fútbol.

El sitio permite mostrar información sobre:

Los servicios que ofrece el complejo (alquiler de canchas, entrenamientos y torneos).
Las distintas actividades deportivas disponibles.
Los próximos torneos organizados.
Un formulario de contacto para consultas o inscripción.
👥 Integrantes del grupo
Agustín Andrada — Desarrollo del sitio (HTML y CSS)
▶️ Instrucciones para visualizar el proyecto
Clonar el repositorio:
git clone https://github.com/Agustin-Andrada/Proyecto-pagina-web-1.git
Ingresar a la carpeta del proyecto:
cd Proyecto Pagina Web1
Abrir el archivo index.html en el navegador:
Doble click sobre el archivo o
Click derecho → "Abrir con" → Navegador
